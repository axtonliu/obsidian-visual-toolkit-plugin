# Support

Obsidian Visual Toolkit is maintained on a best-effort basis.

## Report a problem

After the repository is published, open an issue at:

https://github.com/axtonliu/obsidian-visual-toolkit-plugin/issues

Include:

- The exact user prompt
- Which workflow you expected: Mermaid, Excalidraw, or Obsidian Canvas
- The generated output or file
- The renderer or editor and its version
- The smallest reproducible example

For security or privacy concerns, email [hey@axtonliu.com](mailto:hey@axtonliu.com) instead of posting sensitive information publicly.
